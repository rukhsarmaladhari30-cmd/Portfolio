C++ Core DSA Architecture Engine

Vectors, Hash Maps, MergeSort & QuickSort implementations

1. Vector Storage (std::vector<Transaction>)

Dynamic sequential array storing records with contiguous memory layout. Provides amortized O(1) push_back insertion and O(1) constant-time indexing.

2. Category Inverted Index (std::unordered_map<string, vector<int>>)

Hash Map with bucket array and hash function hashing category strings. Enables O(1) average lookup time when filtering transactions by Food, Travel, etc.

3. Divide & Conquer Sorting Algorithms

• MergeSort: Stable O(N log N) algorithm dividing records to sort by amount.
• QuickSort: In-place partitioning algorithm sorting by ISO Date (YYYY-MM-DD).

// O(N log N) MergeSort Implementation for Amount
void mergeSortByAmount(std::vector<Transaction>& arr, int left, int right, bool ascending) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSortByAmount(arr, left, mid, ascending);
        mergeSortByAmount(arr, mid + 1, right, ascending);
        mergeByAmount(arr, left, mid, right, ascending);
    }
